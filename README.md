# 桌灵 DeskSpirit

桌灵（DeskSpirit）是一只住在你桌面上的小机器人。它有表情、会转头点头、听得懂简单语音，还会在你摸它的头、夸它可爱的时候撒娇。

## 它是什么

- 固定底座的小型桌面机器人，通过屏幕表情表达开心、委屈、害羞、困倦等状态[1](@index-ref?id=1)
- 两个舵机完成左右转头和上下点头，被摸头、被夸、被叫名字时执行预设撒娇动作[1](@index-ref?id=2)
- 按住按键说话，松开后等待语音回复；摸头单独触发本地即时互动[1](@index-ref?id=3)
- Wi-Fi 断线后自动重连，无法联网时显示离线状态[1](@index-ref?id=4)

## 技术架构

STM32H743（实时控制、音频采集与播放、屏幕表情、舵机动作） + ESP32（Wi-Fi / TLS / WebSocket 转发） + 电脑或云端网关（语音识别、对话模型、语音合成）[1](@index-ref?id=5)

## 当前状态

方案设计 V1.0（2026-10-13）。开发按里程碑推进：动作与显示 → 本地音频 → ESP32 通信 → 网关对话 → 交互打磨，单人估算约 5～7 周[1](@index-ref?id=6)
